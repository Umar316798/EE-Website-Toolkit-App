# ⚡ Electrical Engineering Interactive Toolkit

A modern, responsive web application designed to assist Electrical Engineering students and professionals with common circuit calculations and safety verifications.

🔗 https://ee-website-toolkit-app-eol1.vercel.app/

## 🛠 Features

### 1. 🎨 Resistor Color Decoder
- Interactive 4-band resistor calculator.
- Real-time visualization of color bands.
- Instantly calculates resistance (Ω/kΩ/MΩ) and tolerance.

### 2. 🔢 Network Analysis Calculator
- Solves equivalent resistance for complex **Series** and **Parallel** circuits.
- Dynamic interface allows adding/removing infinite components.

### 3. ⚡ RC Time Constant Estimator
- Calculates the time constant (τ) for RC circuits.
- Estimates charge/discharge times (5τ) for capacitor safety.

### 4. ⚠️ Insulation Safety Monitor
- Simulates high-voltage insulation testing.
- Calculates leakage current and resistance.
- Visual "SAFE" vs "ALARM" status indicators based on safety thresholds.

## 💻 Tech Stack
- **Framework:** React.js (v18)
- **Build Tool:** Vite
- **Styling:** Tailwind CSS
- **Deployment:** Vercel
